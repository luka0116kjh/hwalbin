# HWALBIN · 활빈

국제 CTF 대회에 참가하고 버그 바운티 활동을 하는 해킹팀 활빈의 공식 웹사이트 디자인 데모입니다. 반응형 단일 HTML 페이지로 구성되어 별도의 설치나 빌드 없이 실행할 수 있습니다.

## 실행

`index.html`을 브라우저에서 엽니다. 정적 웹 호스팅을 사용하는 경우 이 파일을 웹 루트에 배치하면 됩니다.

## 구성

- 팀 소개, 연구 분야 탭, 활동 카드, FAQ
- 모바일 메뉴와 페이지 내 탐색
- 다크·라이트 테마 전환 및 기기별 설정 저장
- 키보드 탐색과 모션 감소 설정 지원

HTML, CSS, JavaScript가 `index.html` 안에 포함되어 있습니다. Google Fonts를 불러올 수 없는 환경에서는 시스템 대체 글꼴을 사용합니다.

## 실제 운영 전 교체할 내용

국제 CTF 대회 참가와 버그 바운티 활동은 팀 소개에 반영했습니다. 연구 분야와 스터디 안내 등 나머지 제안 내용은 실제 팀 자료를 확인한 뒤 수정해야 합니다. 대회 실적, 팀원 개인정보, 연락처는 임의로 기재하지 않았습니다. 지원 접수와 외부 메시지 전송 기능은 포함되어 있지 않습니다.
